# Historical MLB Odds Integration Plan

## Context

The model currently shows 10.5% ROI against a **simulated logistic regression market**, not real sportsbooks. This doesn't prove the model beats actual Vegas odds. We need to:

1. Integrate the free ArnavSaraogi MLB odds dataset (2021-2025, 76MB JSON from GitHub)
2. Replace simulated market prices with real DraftKings/FanDuel closing lines
3. Re-test both baseline and leverage-weighted models against actual market prices
4. Determine if the model has genuine predictive edge vs. real sportsbooks

**Goal**: Backtest on 2023-2024 using **real sportsbook closing lines** to get accurate ROI estimates.

### Clean & Normalize Data
**New File**: `clean_historical_odds.py` (standalone script)

**Process**:
1. Load raw JSON via `load_historical_odds()`
2. Filter to DraftKings + FanDuel only
3. Extract closing line timestamps (latest before game start)
4. Convert American odds to probabilities
5. Remove vig per bookmaker, then average
6. Map team names to FanGraphs abbreviations
7. Filter to 2023-2024 seasons only (reduce size)
8. Save to `data/processed/historical_odds_2023_2024.csv`

**Output Schema**:
```csv
date (YYYY-MM-DD), home_team_fg, away_team_fg, market_home_prob, n_bookmakers, source
2023-03-30, NYY, SFG, 0.5821, 2, closing_line
```

## Phase 2: Integrate Odds into Backtest

### Modify backtest.py

**Add New Market Mode** (after line 283):
```python
def _historical_odds_market(test: pd.DataFrame) -> np.ndarray:
    # Load real odds from CSV
    odds_path = Path("data/processed/historical_odds_2023_2024.csv")
    if not odds_path.exists():
        raise FileNotFoundError("Run clean_historical_odds.py first")

    odds = pd.read_csv(odds_path)
    odds["date"] = pd.to_datetime(odds["date"]).dt.strftime("%Y-%m-%d")
    test_copy = test.copy()
    test_copy["date"] = pd.to_datetime(test_copy["date"]).dt.strftime("%Y-%m-%d")

    # Merge on date + teams
    merged = test_copy.merge(
        odds[["date", "home_team_fg", "away_team_fg", "market_home_prob"]],
        on=["date", "home_team_fg", "away_team_fg"],
        how="left"
    )

    # Filter to only games WITH real odds (skip missing)
    real_odds_mask = merged["market_home_prob"].notna()
    n_real = real_odds_mask.sum()
    print(f"Real odds available: {n_real:,} / {len(test):,} games ({n_real/len(test):.1%})")

    if n_real == 0:
        raise ValueError("No matching odds found - check date/team alignment")

    # Return only games with real odds
    return merged[real_odds_mask], merged[real_odds_mask]["market_home_prob"].values
```

## Phase 3: Validation Scripts

### Data Quality Check
**New File**: `validate_historical_odds.py`

**Checks**:
1. Coverage by season (% of known games with odds)
2. Vig distribution (should be 3-6% total)
3. Team name mapping (all 30 teams present?)
4. Date alignment (odds date == game date?)
5. Outlier detection (flag market_home_prob outside [0.20, 0.80])

### Sanity Check Backtest
**Script**: Run `backtest.py --use-historical-odds --min-edge 0.00`
- Bet on ALL games regardless of edge
- **Expected**: ROI ≈ -4% to -5% (vig cost)
- **If ROI > 0%**: Data quality issue (not true closing lines)
- **If ROI < -10%**: Stale lines or bad mapping
